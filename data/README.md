# Bundled data

This directory contains the versioned reference data used by AI Job Copilot:

- `positions.json`: the seven-category, 46-position taxonomy seeded into the application database.
- `jd_samples.json`: a snapshot of 2,537 public job-description samples used by the position reference page.

The samples include source URLs and collection timestamps where available. They are historical reference material, not a claim that an opening is still active or that its salary and requirements remain current.

Local SQLite databases are generated by migrations and are intentionally excluded from version control. Validate or seed the taxonomy from the repository root:

```powershell
python scripts\data\validate_positions.py
python scripts\data\seed_positions.py --dry-run
```
