# 合规缺口记录

记录日期：2026-05-04

本文档记录 AI Job Copilot 在中国《个人信息保护法》(PIPL) 和基本安全最佳实践方面的已知合规缺口。这些问题尚未修复，待后续处理。

---

## 一、用户权利缺失

### 1.1 无账号删除功能
- **违反**：PIPL 第 47 条（删除权）
- **现状**：用户可删除单条分析记录，但无法删除整个账号及关联数据
- **缺失端点**：`DELETE /api/auth/user`

### 1.2 无全量数据导出
- **违反**：PIPL 第 45 条（可携带权）
- **现状**：用户可在历史记录页查看和导出单条记录，但无法一键导出所有个人数据
- **进展**：已新增账号数据导出入口，仍需正式上线前复核导出字段范围和下载安全策略

### 1.3 无法删除聊天记录
- **现状**：聊天对话和消息没有删除端点，用户无法清理对话历史
- **进展**：已新增 AI 对话列表和删除能力，仍需正式上线前复核数据保留和备份删除策略

### 1.4 无密码重置
- **现状**：忘记密码后无法找回，无重置流程

## 二、告知同意缺失

### 2.1 无隐私政策页面
- **违反**：PIPL 第 13、17 条
- **现状**：前端无隐私政策链接或页面
- **进展**：已新增隐私政策页面；面向公众运营前仍需要结合实际部署和模型供应商完成专业法律复核

### 2.2 无用户协议 / 服务条款
- **现状**：注册时无任何协议勾选
- **进展**：已新增用户协议页面和注册勾选，公开上线前需要补充版本留痕

### 2.3 未告知第三方 AI 处理
- **违反**：PIPL 第 23 条
- **现状**：用户简历和对话内容发送至智谱 GLM API，未向用户披露
- **进展**：已在注册勾选、隐私政策和用户协议中披露第三方 AI 处理，公开上线前需要列明实际模型供应商和处理边界

### 2.4 无 Cookie / 数据收集同意
- **现状**：无任何数据收集提示或同意机制

## 三、数据安全不足

### 3.1 敏感数据明文存储
- **现状**：简历原文（含姓名、电话、工作经历等）以明文存入 SQLite `analysis_records.input_text`
- **建议**：至少应做应用层加密，或提示用户敏感信息可脱敏后上传

### 3.2 数据库无加密
- **现状**：SQLite 文件无任何加密保护，有文件系统权限即可读取全部数据

### 3.3 JWT 存 localStorage
- **风险**：XSS 攻击可窃取令牌
- **建议**：考虑 httpOnly cookie 方案或添加 CSRF 保护

### 3.4 登录/注册无速率限制
- **风险**：可被暴力破解或枚举用户
- **进展**：已新增认证接口窗口限流，仍需公开上线前接入持久化/分布式限流存储

### 3.5 无日志与审计
- **现状**：无日志配置，无法追踪数据访问记录
- **进展**：已新增日志脱敏过滤器，避免常见敏感字段、token、邮箱、手机号和超长文本直接进入日志；正式上线前仍需补充审计日志设计

### 3.6 `.env` 含真实 API Key
- **风险**：代码仓库若公开则 API 额度被盗用
- **建议**：将 `.env` 加入 `.gitignore`（当前可能已被追踪）

---

## 四、未成年人保护

### 4.1 无年龄验证
- **违反**：《未成年人个人信息保护规定》
- **现状**：注册无年龄门槛，未满 14 岁用户无任何特殊保护

---

## 五、数据生命周期

### 5.1 无数据保留策略
- **现状**：所有数据无限期保留，无自动清除机制

### 5.2 无数据最小化
- **现状**：上传的完整简历原文全部存储，未做脱敏或最小化处理

## 优先级建议

| 优先级 | 项目 | 原因 |
|--------|------|------|
| P0 | 隐私政策 + 用户协议 + 同意勾选 | 上线前必须，法律硬要求 |
| P0 | 账号删除功能 | 上线前必须，用户基本权利 |
| P0 | `.env` 加入 `.gitignore` | 立即处理，防止密钥泄露 |
| P0 | 第三方 AI 处理告知 | 上线前必须 |
| P1 | 登录/注册速率限制 | 防止暴力破解 |
| P1 | 聊天记录删除 | 用户数据控制权 |
| P1 | 全量数据导出 | 可携带权 |
| P2 | 数据库 / 字段加密 | 数据安全提升 |
| P2 | 年龄验证 | 未成年人保护 |
| P2 | 数据保留策略 | 合规与存储成本 |
| P3 | JWT 存储方案改进 | 安全加固 |
| P3 | 日志与审计 | 运维与合规 |
