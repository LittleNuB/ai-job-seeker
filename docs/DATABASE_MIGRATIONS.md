# Database Migrations

Alembic is the source of truth for database schema changes. Runtime code and seed scripts should not call `Base.metadata.create_all()`.

## Apply Migrations

From the repository root:

```powershell
python scripts\migrate_db.py
```

Or with the backend virtual environment:

```powershell
backend\.venv\Scripts\python.exe scripts\migrate_db.py
```

`start-backend.bat` runs this command before starting FastAPI.

## Existing Local SQLite Databases

If `data\ai_job_copilot.db` already contains the current application tables but has no `alembic_version` table, `scripts\migrate_db.py` stamps it at the current baseline instead of recreating data.

## Create a New Migration

After changing SQLAlchemy models:

```powershell
cd backend
..\.venv\Scripts\alembic.exe revision --autogenerate -m "describe change"
cd ..
python scripts\migrate_db.py
```

Always review autogenerated migrations before committing them.

## Seed Position Data

Run migrations first, then seed:

```powershell
python data\seed_positions.py
```
